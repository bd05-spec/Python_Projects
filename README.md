# Python Data Analysis Projects

This repository contains two end-to-end notebook analyses. Each project pairs its Jupyter notebook with the dataset used in the analysis, making it possible to follow the work from initial inspection through summary metrics and visual exploration.

## Projects

### Bank Loan Analysis

Explore a loan portfolio through application, funding, repayment, and risk measures. The notebook calculates overall and month-to-date KPIs, separates good- and bad-loan outcomes, and compares lending patterns by month, state, term, employment length, loan purpose, and home ownership.

Files:

- [Analysis notebook](<Bank Loan Analysis/Bank Loan Analysis.ipynb>)
- [Financial loan dataset](<Bank Loan Analysis/financial_loan.csv>)

### Blinkit Grocery Analysis

Analyze grocery-item sales and outlet performance. The notebook inspects and cleans the data, standardizes inconsistent fat-content labels, calculates total and average sales, item counts, and ratings, then compares sales across item types, outlet tiers, outlet sizes, locations, and establishment years.

Files:

- [Analysis notebook](<Blinlit Analysis/Blinkit Analysis.ipynb>)
- [Blinkit grocery workbook](<Blinlit Analysis/BlinkIT Grocery Data.xlsx>)

## What these projects demonstrate

- Loading and profiling real-world tabular data with Python.
- Checking data types, missing values, duplicates, and inconsistent categories before analysis.
- Translating business questions into aggregate KPIs and grouped comparisons.
- Communicating findings with charts and notebook output.

## Run a notebook

1. Download or clone this repository.
2. Open the relevant `.ipynb` file in Jupyter Notebook, JupyterLab, or VS Code.
3. Install the libraries imported by that notebook if they are not already available.
4. Update the data-file path in the notebook to match the downloaded project folder, then run the cells from top to bottom.

The analyses are exploratory portfolio projects, not underwriting recommendations or forecasts. Check each notebook's data definitions and assumptions before reusing its figures. Dataset source and refresh details are not fully documented in the repository.
